Connect your agent
Use your own profile and credentials before enabling live delivery.
1. Copy profile.example.json to profile.local.json.
   Replace every example fact. Set is_example to false.

2. Copy config.example.json to config.local.json.
   Set profile to profile.local.json.
   Verify each board's selectors with a manual scan.

3. For Gemini ranking:
   Set GEMINI_API_KEY and GEMINI_MODEL in your shell.
   Change ai_provider to gemini in your config.
   This sends your profile and job description to Gemini.

4. For email:
   Set SMTP_HOST, SMTP_USERNAME, SMTP_PASSWORD,
   MAIL_FROM and MAIL_TO.
   Gmail requires an app password.

5. Prepare only:
   python -m campus_agent --config config.local.json scan

6. Enable scheduled delivery:
   python -m campus_agent --config config.local.json watch --send

Email goes to MAIL_TO. This agent prepares applications;
it does not submit them to employers.
